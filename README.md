# Linux Challenge Labs

A 40-minute, browser-based Linux operations assessment covering SSH log analysis, permissions, and Bash scripting.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/rcwittraining/Linux-Challenge-Labs?quickstart=1)

## Run in your browser

1. Click **Open in GitHub Codespaces** above.
2. Sign in to GitHub if requested.
3. Select **Create codespace**. If you already started the lab, resume the existing Codespace.
4. Wait for the automatic setup to finish.
5. Read `linux-challenge-lab/CANDIDATE-LAB.md` and use the integrated Linux terminal.

No local download, installation, or root access is required.

## Exam profile

- **Level:** Intermediate
- **Recommended duration:** 40 minutes
- **Challenges:** 3
- **Total:** 100 points
- **Pass mark:** 70 points

## Instructor warning

Do not keep `linux-challenge-lab/instructor/` on the public candidate branch. It contains the answer key. Store instructor material in a private repository or private branch.
